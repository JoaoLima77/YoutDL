# Yout Downloader

Aplicativo desktop desenvolvido em **Python** para download de vídeos do YouTube e conversão de vídeos em arquivos de áudio.

O projeto possui uma interface gráfica simples e intuitiva, permitindo escolher o formato, a qualidade e a pasta de destino dos arquivos.

## 1. Tecnologias utilizadas

O projeto foi construído utilizando as seguintes tecnologias e bibliotecas:

- **Python** — Linguagem principal
- **CustomTkinter** — Interface gráfica
- **yt-dlp** — Extração e download das mídias
- **imageio-ffmpeg** — Integração e conversão de mídia com FFmpeg

## 3. Como executar o projeto localmente

Siga os passos abaixo para executar a aplicação no seu computador.

### 3.1. Clone o repositório

    git clone https://github.com/JoaoLima77/downloadertube.git

Entre na pasta do projeto:

    cd downloadertube

### 3.2. Instale as dependências

Instale as dependências utilizando o arquivo `requirements.txt`:

    pip install -r requirements.txt

Ou instale manualmente:

    pip install customtkinter yt-dlp imageio-ffmpeg

### 3.3. Execute o programa

Após instalar as dependências, execute:

    python main.py
